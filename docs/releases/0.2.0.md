# MyMCP 0.2.0: public-host cutover

> Planned GitHub release body. This release has not been tagged or published.

## Delivered local cutover candidate

MyMCP/`mymcp` `0.2.0` is the local public-host cutover candidate. It identifies
the host endpoint and server marker, FastAPI application, Python distribution and
package, and tracked OpenCode connection and agent as MyMCP/`mymcp`.

The canonical repository target is <https://github.com/flyset/MyMCP>. The tracked
OpenCode policy is deny-first: it denies `mymcp_*`, allows exactly `list_tools`,
`memory_recall`, `memory_inspect`, and `memory_list`, then requires `ask` for
the five exact mutations: `memory_remember`, `memory_revise`,
`memory_archive`, `memory_restore`, and `memory_forget`.

## Compatibility preserved

- Routes and MCP protocol remain unchanged: `/mcp`, `/health`, `/version`, and
  host-owned `list_tools`.
- Mnemosyne remains bundled plugin `mnemosyne` at version `0.1.0`.
- All `memory_*` Tool names, schemas, ordering, results, errors, and mutation
  gates remain compatible.
- `MNEMOSYNE_*`, `~/.mnemosyne`, memory storage, record formats and paths,
  content-free logging, and explicit consent semantics remain preserved.

## Validation and publication status

The candidate has not yet completed the required operational or publication
steps. Repository rename and remote verification, client restart/reconnect,
direct denial/no-call and exact-call approval checks, annotated tag creation,
and GitHub release publication remain pending. This body must not be treated as
evidence that any of those steps occurred.

## Deferred work

Native external plugin installation, activation, and isolation; lifecycle
publication; and client-neutral gateway governance remain deferred. No claim is
