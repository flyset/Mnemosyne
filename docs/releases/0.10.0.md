# MyMCP 0.10.0: configurable MCP session lifetimes

Schema 7 preserves schema 6 and adds required `[mcp]` keys
`session_inactivity_timeout_seconds` and
`session_absolute_lifetime_seconds`. Each accepts a native TOML integer from
`0` through `2,592,000` seconds; `0` disables only that expiry limit. Schemas
1–6 and absent configuration retain strict protocol behavior and the prior
30-minute inactivity / 8-hour absolute defaults.

The settings are immutable for the process and require restart to change.
Sessions remain host-owned, process-local, authenticated on every use, bound to
the principal and runtime generation, capped at 128 active sessions, and
explicitly terminable. Both limits may be disabled without adding persistence,
renewal, cleanup, or hot reconfiguration.

MCP revision `2025-11-25`, HTTP paths and status classes, Authentication
contract and OAuth/operator-bearer behavior, plugin contracts, and all
Mnemosyne Tools, configuration, storage, records, and lifecycle semantics are
unchanged. Governance remains deferred.
